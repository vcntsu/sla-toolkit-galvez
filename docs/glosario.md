# Glosario

| Término | Significado |
|---------|-------------|
| **BDP** | *Bandwidth-Delay Product*: ancho de banda × RTT. Bits "en vuelo" que la ventana TCP debe cubrir (RFC 6349). |
| **Crédito de servicio** | Descuento que recibe el cliente cuando el proveedor incumple un SLO. |
| **Demarcación** | Punto físico o lógico donde termina la responsabilidad del proveedor. |
| **Disponibilidad** | Porcentaje del tiempo acordado en que el servicio está operativo. |
| **IPDV** | *IP Packet Delay Variation*: variación del retardo entre paquetes (RFC 3393). Base del jitter. |
| **IPLR / IPTD** | Tasa de pérdida / tiempo de transferencia de paquetes IP (Y.1540). |
| **ITIL 4** | Marco de buenas prácticas de gestión de servicios de TI. |
| **Jitter** | Variación del retardo de los paquetes. |
| **MEF** | Metro Ethernet Forum; define servicios Carrier Ethernet. |
| **MTBF** | *Mean Time Between Failures*: tiempo medio entre fallas. |
| **MTTR** | *Mean Time To Repair/Restore*: tiempo medio de reparación o restablecimiento. |
| **OLA** | *Operational Level Agreement*: acuerdo entre áreas internas del proveedor que sostiene el SLA. |
| **PDCA** | Planificar–Hacer–Verificar–Actuar: ciclo de mejora continua (ISO/IEC 20000-1). |
| **Percentil (pXX)** | Valor bajo el cual está el XX % de las muestras (p95 = 95 %). |
| **QoS** | *Quality of Service*: calidad de servicio; clases de tráfico con objetivos distintos. |
| **RTT** | *Round-Trip Time*: tiempo de ida y vuelta. |
| **SLA** | *Service Level Agreement*: acuerdo formal entre proveedor y cliente con niveles de servicio y consecuencias. |
| **SLI** | *Service Level Indicator*: métrica medible del servicio (ej. latencia p95). |
| **SLM** | *Service Level Management*: práctica de ITIL que gestiona los SLA. |
| **SLO** | *Service Level Objective*: valor objetivo de un SLI (ej. ≤ 20 ms). |
| **SLR** | *Service Level Requirement*: necesidad del cliente expresada en su lenguaje. |
| **Throughput** | Tasa efectiva de datos transferidos (bit/s). |
| **TWAMP** | *Two-Way Active Measurement Protocol* (RFC 5357). |
| **UC** | *Underpinning Contract*: contrato con un proveedor externo que sostiene el SLA. |
